Problem Statement



Objective

To analyze a CSV dataset using Python and Pandas, perform the data transformations taught in class, handle null values using mean imputation, generate meaningful insights, and visualize the findings.



Problem Description

Select a dataset in CSV format based on your interest, such as Zomato, Spotify, IMDb, sales, or any other relevant dataset available on Kaggle or another online source. 



Dataset Size: Choose a dataset with a sufficient number of records to explore and analyze. The larger and more diverse the dataset, the more opportunities you will have to practice data transformation, handle null values, and generate meaningful insights. Prefer larger datasets wherever possible.



Using the selected dataset, perform the following tasks:





Dataset Selection and Reading





Find and download a relevant dataset in CSV format.



Read the CSV file using Pandas.



Data Understanding





Study the dataset and understand its structure and contents.



Data Transformation





Perform the required transformations, such as changing data types, dropping unnecessary columns, or adding new columns.



Handling Null Values





Identify null values in the dataset.



Handle null values using mean imputation wherever applicable.



Insight Generation





Generate meaningful insights from the dataset using the concepts taught in class.



Examples include sales trends over time and region-wise revenue analysis, depending on the selected dataset.





Data Visualization





Visualize the generated insights using appropriate charts.
